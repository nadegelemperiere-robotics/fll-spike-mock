1. Movement

1.1 Pair the drive motors

Before driving, tell the program which two motors form the drive base. Always pair before any movement command. Pair only once per program!

import motor_pair
from hub import port
import runloop


async def main():
    motor_pair.pair(motor_pair.PAIR_1, port.A, port.E)


runloop.run(main())
If A and E are swapped, the robot will turn the opposite way to what you expect — pair order matters.

1.2 Drive forward

steering=0 means perfectly straight. Positive velocity = forward.

import motor_pair
from hub import port
import runloop


async def main():
    motor_pair.pair(motor_pair.PAIR_1, port.A, port.E)
    await motor_pair.move_for_time(motor_pair.PAIR_1, 2000, 0, velocity=400)


runloop.run(main())
2000 = duration in milliseconds (2 seconds). velocity is in degrees per second; 400 deg/s ≈ 35 cm/s on standard wheels.

1.3 Drive backward

Same command, but with a negative velocity. The robot keeps facing forward — it just rolls in reverse.

import motor_pair
from hub import port
import runloop


async def main():
    motor_pair.pair(motor_pair.PAIR_1, port.A, port.E)
    await motor_pair.move_for_time(motor_pair.PAIR_1, 1500, 0, velocity=-400)


runloop.run(main())
Robot still faces forward (chevron up) but rolls in reverse — that's exactly what a real SPIKE robot does with negative velocity.

1.4 Drive a precise distance

Use move_for_degrees when you need exact distance. The number is the wheel rotation in degrees — not centimeters.

import motor_pair
from hub import port
import runloop


async def main():
    motor_pair.pair(motor_pair.PAIR_1, port.A, port.E)
    # 720° = 2 full wheel turns ≈ 35 cm with standard wheels
    await motor_pair.move_for_degrees(motor_pair.PAIR_1, 720, 0, velocity=400)


runloop.run(main())
Same speed, but the 720° robot rolls for twice as long → it travels twice as far. To convert: 360° = 1 wheel turn = π × wheel diameter ≈ 17.6 cm with the standard SPIKE wheels (Ø 56 mm).

1.5 Curve while moving

The steering parameter (−100 to +100) bends the path. Negative = left, positive = right. ±100 stops the inside wheel completely → tightest curve.

import motor_pair
from hub import port
import runloop


async def main():
    motor_pair.pair(motor_pair.PAIR_1, port.A, port.E)
    # Try one of these — see the animation for what each does:
    #   -100 = sharp left   |   -50 = gentle left
    #    +50 = gentle right  |  +100 = sharp right
    await motor_pair.move_for_time(motor_pair.PAIR_1, 2000, 50, velocity=400)


runloop.run(main())
±100 stops the inside wheel completely → the robot pivots tightly. ±50 keeps both wheels moving but at different speeds → wider curve. 0 = perfectly straight.

1.6 Pivot in place

move_tank sets each wheel velocity directly. Equal but opposite velocities → the robot spins around its own center.

import motor_pair
from hub import port
import runloop


async def main():
    motor_pair.pair(motor_pair.PAIR_1, port.A, port.E)
    motor_pair.move_tank(motor_pair.PAIR_1, 400, -400)
    await runloop.sleep_ms(1000)
    motor_pair.stop(motor_pair.PAIR_1)


runloop.run(main())
Left wheel positive, right wheel negative → spin clockwise (viewed from above). Swap the signs for the opposite direction.

1.7 Pivot on one wheel

Set one wheel velocity to 0 — the robot pivots around that wheel.

import motor_pair
from hub import port
import runloop


async def main():
    motor_pair.pair(motor_pair.PAIR_1, port.A, port.E)
    # Right wheel still, left wheel drives → pivot on right wheel
    motor_pair.move_tank(motor_pair.PAIR_1, 400, 0)
    await runloop.sleep_ms(1500)
    motor_pair.stop(motor_pair.PAIR_1)


runloop.run(main())
Same idea with left = 0 and right driven → robot pivots on the left wheel.

1.8 Chain moves & stop

Blocking commands (move_for_time, move_for_degrees) finish on their own. Non-blocking ones (move, move_tank) keep going — always end your sequence with motor_pair.stop().

import motor_pair
from hub import port
import runloop


async def main():
    motor_pair.pair(motor_pair.PAIR_1, port.A, port.E)
    await motor_pair.move_for_time(motor_pair.PAIR_1, 1000, 0, velocity=400)
    await motor_pair.move_tank_for_time(motor_pair.PAIR_1, 600, 300, -300)
    motor_pair.stop(motor_pair.PAIR_1)


runloop.run(main())

2. Color sensor

2.1 Stop on a colored line

Drive forward, keep checking the sensor, stop the moment a red line is detected.

import color
import color_sensor
import motor_pair
from hub import port
import runloop


async def main():
    motor_pair.pair(motor_pair.PAIR_1, port.A, port.E)
    motor_pair.move(motor_pair.PAIR_1, 0, velocity=300)
    while color_sensor.color(port.B) != color.RED:
        pass
    motor_pair.stop(motor_pair.PAIR_1)


runloop.run(main())
The while loop keeps spinning until the condition becomes false. Each iteration takes a few ms because reading the sensor talks to the hub over Bluetooth.

3. Gyroscope

3.1 Turn an exact angle

Reset the yaw to 0 right before turning so you measure from a known starting point. Then drive in one direction until the yaw reaches the target. The angle is in deci-degrees — to turn 90° you wait until tilt_angles()[0] reaches 900.

from hub import motion_sensor, port
import motor_pair
import runloop


async def main():
    motor_pair.pair(motor_pair.PAIR_1, port.A, port.E)
    motion_sensor.reset_yaw(0)
    motor_pair.move(motor_pair.PAIR_1, -100, velocity=200)
    while motion_sensor.tilt_angles()[0] < 900:
        pass
    motor_pair.stop(motor_pair.PAIR_1)


runloop.run(main())
Convention: in our simulator, turning left increases the yaw (positive); turning right decreases it. To turn 90° to the right, use steering=+100 and wait for yaw < -900.
